# Amenazas

LinkSight presenta un riesgo inherente porque es una herramienta capaz de detectar vulnerabilidades y realizar pruebas sobre aplicaciones web. Por este motivo, debe diseñarse desde el principio para funcionar únicamente dentro de un contexto de auditoría autorizada.

Por otro lado, el servidor bastión representa un elemento crítico de la infraestructura, ya que constituye el punto de acceso administrativo hacia los sistemas internos. Su compromiso podría facilitar el acceso a otros recursos de la red. Para reducir este riesgo se aplicarán medidas de bastionado, mínimo privilegio, autenticación mediante claves, segmentación mediante DMZ, reglas de firewall restrictivas, actualización continua y centralización de registros.

De esta forma, la seguridad no se limita al análisis de las vulnerabilidades de las aplicaciones, sino que también se aplica a la propia infraestructura utilizada para realizar las auditorías.
